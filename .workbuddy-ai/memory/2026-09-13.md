# 2026-09-13 — Review & fix SiteGPT (RAG chatbot)

Reviewed the whole site-gpt backend (FastAPI + pgvector + Redis worker) and fixed core bugs.

## Critical fixes
- `services/rag.py::search` only queried `documents` (crawled pages) → chat ignored all uploaded docs. Rewrote to UNION `documents` (by website_id) + `extra_documents` (by website_id OR company_id). Added system-prompt guard.
- `worker.py` crashed with `KeyError: 'title'` (crawler never set metadata title). `crawler.crawl_page` now returns `(title, text)`; worker upserts pages by URL; wrapped in try/except → `ingest_status='failed'` on error.
- Uploaded files were never embedded. Added `services/parse.py` (txt/md/csv/json/html/pdf/docx; new deps pypdf + python-docx). Worker now embeds extra-doc text + attachment contents, including company-wide (website_id IS NULL) extra docs.
- Re-ingest idempotent: `ingest_document`/`ingest_extra_document` delete old chunks first.

## Security / correctness
- `POST /api/ingest` now requires manager/admin + ownership (was public).
- `GET/PUT /api/settings` scoped to company (was leaking other companies).
- Upload: UUID filenames (collision + path-traversal safe).
- Forgot/reset password rewritten with 30-min token + email link + expiry check. Added `reset_token`/`reset_token_expires_at` (model + migration `3f1a9c0d7e22`).
- Fixed `services/mail.py` for installed fastapi-mail (MAIL_STARTTLS/MAIL_SSL_TLS) — was breaking app import.
- Removed dead dual vector backend (`db/vector_store.py`, `ingest_documents`).
- CORS: `allow_credentials` auto-disabled when `CORS_ORIGINS=*`. Added `FRONTEND_URL`, `CORS_ORIGINS` to config + .env.example.
- Fixed dead `chat`/`ingest` helpers in frontend `api.ts`.

## Verification
- `.venv` exists; `import site_gpt.app.main` and all routers/services/worker import OK after fixes.
- All changed .py files pass `py_compile`.
- Note: embeddings column is `Vector(1536)`; ollama nomic-embed (768) would mismatch — documented in README.
